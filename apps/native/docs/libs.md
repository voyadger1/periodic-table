# Установка необходимых библиотек

Для React Native 0.60 и выше автолинковка должна сработать автоматически. Для iOS вам также нужно будет перейти в папку ios и установить Pod'ы:

```shell
cd ios && pod install
```

---

WebView

```shell
npm install --save react-native-webview
```

expo-file-system для сборки под WebView

```shell
npm install expo-file-system
```
